# Afterimage 3D scene prototype V2

Frozen version of the interactive WebGPU desert scene.

[Open the scene](https://qzq99999.github.io/afterimage-3d-scene-prototype-v2/)

## Controls

- W / A / S / D: move the red ball and leave tracks.
- Drag: orbit the camera. Scroll: zoom.
- The scene panel controls sunlight, fog, Tyndall shafts, environment and sand.

Use a browser with WebGPU and GPU acceleration enabled. GitHub Pages serves the scene over HTTPS; for local use, serve this directory from localhost.

## Frozen snapshot

`index.html` and `Afterimage 3D scene prototype V2.html` are byte-for-byte copies of the approved local version. Their SHA-256 digests are recorded in `SNAPSHOT.sha256`.

Further edits, updates or redeployment require explicit user confirmation. The initial publication preserves the scene without source changes.
